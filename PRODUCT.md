# Cristobal Valencia — AI Engineer Portfolio

## Purpose
Personal professional portfolio showcasing AI engineering expertise, featured projects, and contact information. Surface type: **Experience** (portfolio/showcase).

## Audience
- Tech recruiters at AI/fintech companies
- Startup founders looking for AI/backend engineers  
- Potential collaborators in AI automation and LLM infrastructure
- Enterprise teams building agentic systems

## Core Message
"I build production-grade AI agents and backend infrastructure. 4+ years of backend engineering, 50x efficiency gains at Rappi, 15+ smart contracts, tech lead experience."

## Brand Voice
- Technical depth: demonstrates real expertise, not marketing speak
- Approachable: human, direct, no unnecessary jargon
- Ambitious: shipping real systems, pushing boundaries
- Authentic: shows actual work, real case studies

## Product Reality
- Static HTML portfolio (no backend)
- Deployed on Vercel
- Showcases 6 featured projects with direct GitHub links
- Contact methods: email, WhatsApp, LinkedIn, GitHub
- Updated resume/skills section
- No third-party form processing

## Success Metrics
1. First impression: "This person knows AI systems"
2. Project showcase: Clear what each project does + tech stack
3. Credibility: Case study (50x efficiency, Rappi) immediately visible
4. Call-to-action: Easy to reach out (multiple contact methods)

## Constraints
- Must remain static HTML (no build step, no backend)
- Hosted on Vercel
- Mobile-first responsive
- Performance critical (portfolio is first impression)
- Self-contained styling (no external CSS frameworks beyond icons)

## Design Direction
**"Premium technical showcase"** — the aesthetic of someone who ships production code. High signal-to-noise ratio. Elegant, not flashy. Respects the viewer's time. Uses sophisticated color, precision spacing, and purposeful motion to convey mastery.

Comparable references:
- GitHub profiles of prominent ML engineers (clarity, no clutter)
- Technical blogs by industry leaders (sophisticated but not overdesigned)
- High-end SaaS dashboards (professional, calm, functional)

Anti-references:
- Template portfolios (generic, overused, signals junior level)
- Overly animated portfolios (distraction over substance)
- Flat design from 2015 (dated, uninspiring)
- Neon gradients / VaporWave aesthetic (signals gamedev, not serious engineering)
